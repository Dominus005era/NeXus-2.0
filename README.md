# ?? NEXUS 2.0: Autonomous AI Operating System for Business Decisions

> **"Don't just monitor your business. Let it reason about itself."**

NEXUS 2.0 is the next-generation multi-agent operational decision engine connecting **Sales**, **Inventory**, and **Finance** departments with real-time shared world state, Role-Based Knowledge Access (RBAC), and deterministic Integer Linear Optimization.


## ?? Live Vercel Deployment Configuration

When importing this repository into **Vercel**:
* **Framework Preset**: `Vite`
* **Root Directory**: `Nexus 2.0/frontend`
* **Build Command**: `npm run build`
* **Output Directory**: `dist`
* **Install Command**: `npm install`
